1. The Classroom Problem

Back-row glare makes board derivations unreadable, students miss spoken context while copying equations, and teachers spend hours after class preparing revision material.

2. Zero-Hardware Solution

Uses only the presenter's existing laptop camera and mic to audit display legibility, auto-capture board ink states, and transcribe spoken explanations into editable notes.

3. Why Not a Generic Note App?

Generic note apps only record text. BoardIQ links physical classroom ergonomics (glare & safe-zone checks), optical board snapshots, and live Lecture-to-Learning synthesis.

4. Privacy & Honest Scope

Camera faces the display, never the students—zero attention surveillance. Works immediately with sample data or optional live permissions.

System Configuration & Disclosures

Permissions, Capabilities & Scope

Camera Input (getUserMedia) Off (Sample Mode)

Never starts automatically. When enabled by the user, checks display readability and captures board frames locally in browser memory.

Microphone & Web Speech Off (Sample Mode)

Never starts automatically. Uses Web Audio API for acoustic level monitoring and browser Web Speech API for live transcription where supported.

Product Scope & Engineering Disclosures

  • Hackyard 2026 Prototype: BenQ BoardIQ is an independent student prototype built for Hackyard 2026 at IIT Guwahati demonstrating how any classroom display can become an intelligent teaching workspace without installing additional hardware sensors. It does not claim official BenQ integration or endorsement beyond hackathon sponsorship.
  • Zero Student Attention Surveillance: BoardIQ evaluates display legibility, board ink changes, and instructor speaking cadence. It never performs student facial recognition or attention tracking.
  • OCR, Synthesis & Speech Transparency: Browser speech recognition relies on the browser's speech engine. Board text extraction and Lecture-to-Learning synthesis use deterministic client-side heuristics with full inline instructor editing rather than claiming infallible OCR or external cloud AI.
  • Local Browser Persistence: Session state is stored in `localStorage` on the local machine until cleared or exported.
